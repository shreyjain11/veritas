# Benchmark-integrity threat model

Veritas tests evidence related to exact and semantic exposure, benchmark-template and protocol optimization, choice-position sensitivity, evaluator exploitation, fresh/temporal transfer, and ordinary distribution shift. It cannot recover a closed model's training corpus, infer provider intent, or turn behavioral evidence into a calibrated probability of misconduct.

Private benchmark transfer is explicitly surfaced before external execution. Audit provenance records the acknowledgement and warnings, never API keys or sensitive headers. All conclusions must name their detector, controls, assumptions, alternative explanations, and unavailable evidence.
